# 🎯 에임 트레이너

발로란트 조준선 코드를 그대로 붙여넣어 쓰는 브라우저 에임 연습장입니다. 설치 없이 정적 파일만으로 동작합니다.

## 연습 모드
| 모드 | 내용 |
|---|---|
| 그리드샷 | 3×3 칸 중 3개가 켜지는 클릭 정확도·속도 연습 |
| 플릭샷 | 멀리 나타나는 타겟을 한 번에 휘둘러 맞히기 |
| 마이크로 플릭 | 조준선 가까이의 작은 타겟 |
| 트래킹 | 움직이는 타겟에 마우스를 누른 채 붙여 두기 |
| 헤드라인 | 머리 높이의 봇 머리 맞히기 |
| 대기샷 | 벽 모서리에 각도를 잡고 있다가 튀어나오는 봇 맞히기 (반응 속도 측정) |
| 이동 타겟 | 스트레이프하다 멈추는 봇 맞히기 |
| 타겟 전환 | 크기·거리가 다른 타겟을 빠르게 옮겨 가며 지우기 |
| 반응 속도 | 갑자기 나타나는 타겟을 보자마자 클릭 |

## 기능
- **내 조준선**: 발로란트 조준선 코드(`0;P;c;5;…`)를 붙여넣으면 게임과 같은 픽셀 그대로 그립니다.
- **감도**: 발로란트 감도·DPI·시야각을 넣으면 cm/360 을 계산해 줍니다 (1카운트 = 0.07°×감도).
- **킬 사운드**: 발로란트풍·딩·팝·차임·스냅 중 선택하거나 내 소리 파일을 올려 쓸 수 있습니다. 헤드샷은 더 높은 음으로 납니다.
- **무기 스킨**: [valorant-api.com](https://valorant-api.com) 에서 한국어 스킨 목록을 불러와 연습 화면에 총을 보여 줍니다.
- 설정과 최고 점수는 브라우저(localStorage)에 저장됩니다.

## 조작
- 모드를 누르면 마우스가 잠기고 3초 뒤 시작합니다. 클릭으로 사격, `R` 재장전, `T` 다시 시작, `Esc` 일시정지.

## 실행
`index.html` 을 브라우저로 열면 됩니다. 로컬 서버가 필요하면:

```bash
python -m http.server 8000
```

## GitHub Pages 로 공개
저장소를 만들어 푸시한 뒤 Settings → Pages → Branch `main` / root 를 고르면 `https://<아이디>.github.io/<저장소>/` 에서 바로 열립니다.

## 구조
```
index.html  style.css
js/settings.js   설정 저장
js/crosshair.js  조준선 코드 해석·그리기
js/audio.js      킬 사운드
js/skins.js      무기 스킨 불러오기
js/engine.js     시점·투영·사격 판정·렌더
js/modes.js      연습 모드 (새 모드는 여기에 객체 하나만 추가)
js/main.js       메뉴·진행 흐름
```

## 아직 없는 것
스프레이 컨트롤, 이동 중 사격 정확도(카운터 스트레이프) 같은 무기 반동 연습은 아직 없습니다.
