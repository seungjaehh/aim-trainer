# 🎯 에임 트레이너

발로란트 조준선 코드를 그대로 붙여넣어 쓰는 브라우저 에임 연습장입니다. 설치 없이 정적 파일만으로 동작합니다.

공개 연습장: https://seungjaehh.github.io/aim-trainer/

조준선은 화면 중앙에 고정되고 마우스로 시점을 회전합니다. 바닥 타일·거리선·벽의 눈높이 띠와 표적에 하나의 원근 투영을 적용해, 위아래로 바라볼 때도 공간의 기준이 유지됩니다. 봇은 바닥에 서 있고 발밑에 그림자가 표시됩니다. 왼쪽 아래에서 현재 시선의 상하 각도를 확인할 수 있습니다.

## 연습 모드
| 모드 | 내용 |
|---|---|
| 그리드샷 | 3×3 칸 중 3개가 켜지는 클릭 정확도·속도 연습 |
| 플릭샷 | 멀리 나타나는 타겟을 한 번에 휘둘러 맞히기 |
| 마이크로 플릭 | 조준선 가까이의 작은 타겟 |
| 트래킹 | 움직이는 타겟에 마우스를 누른 채 붙여 두기 |
| 헤드라인 | 머리 높이의 봇 머리 맞히기 |
| 대기샷 | 벽 모서리에 각도를 잡고 있다가 튀어나오는 봇 맞히기 (반응 속도 측정) |
| 이동 타겟 | 스트레이프하다 멈추는 봇 맞히기 |
| 타겟 전환 | 크기·거리가 다른 타겟을 빠르게 옮겨 가며 지우기 |
| 반응 속도 | 갑자기 나타나는 타겟을 보자마자 클릭 |
| 감도 맞추기 | 타겟이 뜨면 한 번에 휘두르고, 첫 동작이 멈춘 위치로 새 감도를 추천 |
| 프리에임 (코너 클리어) | A/D 로 벽 옆으로 나가며, 모서리 선 위 머리 높이에 미리 둔 조준선으로 적 맞히기. 드러난 순간의 조준 오차를 잽니다 |
| 피킹 (스윙 & 스톱) | 표시된 자리까지 넓게 나갔다가 멈추고 쏘기. 멈춘 뒤 쐈는지, 노출 시간이 얼마였는지 기록 |
| 지글 피크 (샷 유도) | 어깨만 살짝 보였다 들어와 저격수의 한 발을 빼낸 뒤 다시 나가 잡기 |
| 카운터 스트레이프 | 좌우로 달리다 반대 키로 멈춘 순간에 쏘기. 발사 시점의 속도를 보여 줍니다 |
| 탭 · 버스트 · 스프레이 | 거리에 맞는 발수로 쏘기. 연사하면 탄이 위로 올라갑니다 |
| 발로란트 실전 루틴 | 헤드라인 → 프리에임 → 대기샷 → 카운터 스트레이프 → 피킹 → 지글 → 발수 조절, 약 9분 |
| 하루 루틴 | 9개 모드를 정해진 순서로 이어서 하는 약 11분 코스 (워밍업 → 플릭 → 트래킹 → 대기샷 → 반응) |

대기샷은 연습 설정에서 칼 달리기(6.75 m/s)·밴달 달리기(5.40 m/s)·밴달 걷기(3.24 m/s)·앉기(약 1.90 m/s)를 고정하거나 랜덤으로 섞을 수 있습니다. 각속도가 아닌 바닥 위의 실제 거리를 기준으로 이동하며, 앉기 봇은 머리 높이도 낮아집니다. 스킬·버프는 제외합니다. [리플레이 실측 자료](https://github.com/yakisoba0728/vrfkit/blob/main/docs/DATA.md)를 참고한 연습용 근사이며, 라이엇이 공식 보증한 물리 재현은 아닙니다.

## 기능
- **내 조준선**: 발로란트 조준선 코드(`0;P;c;5;…`)를 붙여넣으면 게임과 같은 픽셀 그대로 그립니다.
- **감도**: 발로란트 감도·DPI·시야각을 넣으면 cm/360 을 계산해 줍니다 (1카운트 = 0.07°×감도).
- **킬 사운드**: 발로란트풍·딩·팝·차임·스냅 중 선택하거나 내 소리 파일을 올려 쓸 수 있습니다. 헤드샷은 더 높은 음으로 납니다.
- **밴달 스킨**: 밴달은 고정이며 [valorant-api.com](https://valorant-api.com) 에서 불러온 스킨만 선택합니다.
- **배경**: 바닥과 거리선이 있는 연습장·어두운 연습장·기존 격자 중 선택합니다.
- **빗나간 샷 분석**: 판이 끝나면 모든 샷을 가장 가까운 타겟 기준으로 지도에 찍고, 오버플릭·언더플릭, 움직이는 타겟을 앞서/뒤처져 쐈는지, 머리 위·아래로 빗나갔는지를 세어 가장 큰 문제 하나를 팁으로 알려 줍니다. 트래킹은 타겟에서 벗어난 시간을 방향별로 나눠 보여 줍니다.
- **감도 맞추기**: 24번의 플릭에서 첫 동작이 타겟 거리의 몇 %에서 멈췄는지 재서, 95%(살짝 모자라게 멈추고 미세 조정)를 기준으로 새 감도를 계산합니다. 한 번에 −20%~+25% 안에서만 바꾸고, 결과가 들쭉날쭉하면 절반만 반영합니다.
- **성장 기록**: 모드별로 최근 200판을 저장해 점수 추세(5판 이동 평균 포함), 최근 5판 평균, 그 전 5판 대비 변화를 보여 줍니다. 결과 화면에서도 평소(최근 10판 평균) 대비 점수가 나옵니다.
- **하루 루틴**: 단계 사이에 마우스를 놓지 않고 이어서 진행하며, 끝나면 모드별 평소 대비 결과·약한 모드·연속 일수를 보여 줍니다.
- 발로란트 실전 모드는 시작 전과 결과 화면에 훈련 요령과 근거 자료 링크를 보여 줍니다.
- 킬 배너: 연속 킬 수(최대 5단계)를 화면 아래에 표시합니다. 직접 그린 도안이며 게임 원본 배너가 아닙니다. `assets/skins/manifest.json` 항목에 `banners`(1~5킬 이미지 파일 이름)를 넣으면 그 이미지를 대신 씁니다.
- 그래픽: Blender 로 만든 사격장·봇 모델과 Cycles 로 구운 조명을 three.js 로 그립니다. 설정에서 2D 로 바꿀 수 있고, three.js(CDN)를 못 불러오거나 WebGL 이 없으면 자동으로 2D 로 돌아갑니다.
- 설정·최고 점수·기록은 브라우저(localStorage)에 저장됩니다.

## 조작
- 모드를 누르면 마우스가 잠기고 3초 뒤 시작합니다. 클릭으로 사격, `T` 다시 시작, `Esc` 일시정지.
- 발로란트 실전 모드: `A` / `D`(또는 ←/→) 좌우 이동, `Shift` 걷기. 움직이며 쏘면 탄이 퍼집니다.

## 훈련 근거
실전 모드의 규칙과 요령은 아래 자료를 바탕으로 했습니다. 수치가 공개되지 않은 부분(탄 퍼짐 각도, 반동 궤적, 봇 반응 시간 등)은 연습용 근사이며 게임 원본 값이 아닙니다.

- 멈추는 시간: 키를 떼면 약 0.17초, 반대 키를 누르면 약 0.16초. 최고 속도의 30% 아래에서 정확도 회복, 걷기는 달리기의 약 60% — [Riot 개발자 측정 감속 데이터 정리](https://turbosmurfs.gg/?p=7691)

## 스킨·킬사운드 자산
- 스킨 이름과 이미지는 실행 중에 [valorant-api.com](https://valorant-api.com) 에서 불러옵니다(저장소에 복사하지 않음).
- `assets/skins/` 에는 가이아·챔피언스 2021 밴달의 총 이미지와 1~5킬 소리가 들어 있습니다. `manifest.json` 에 스킨 UUID, 파일 해시(sha256), 출처, 권리 상태를 적어 두었습니다.
- 이 자산들은 Riot Games 의 것이며, 이 프로젝트는 사용 허가를 확인하지 않았습니다(`rightsStatus: unresolved`). 이 프로젝트는 Riot Games 와 관계가 없습니다.
- 다른 스킨은 설정에서 직접 이미지·소리를 올리면 그 브라우저에만 저장됩니다. 올린 파일의 권리 문제는 올린 사람이 확인해야 합니다.

## 실행
`index.html` 을 브라우저로 열면 됩니다. 로컬 서버가 필요하면:

```bash
python -m http.server 8000
```

저장소를 만들어 푸시한 뒤 Settings → Pages → Branch `main` / root 를 고르면 `https://<아이디>.github.io/<저장소>/` 에서 바로 열립니다.

```
index.html  style.css
js/settings.js   설정 저장
js/crosshair.js  조준선 코드 해석·그리기
js/audio.js      킬 사운드
js/skins.js      무기 스킨 불러오기
js/engine.js     시점·투영·사격 판정·렌더
js/modes.js      연습 모드 (새 모드는 여기에 객체 하나만 추가)
js/valorant.js   발로란트 실전 모드 (프리에임·피킹·지글·카운터 스트레이프·발수 조절)
js/scene3d.js    three.js 3D 화면 (없으면 2D 로 동작)
assets/models/   Blender 로 만든 사격장·봇 모델과 구운 조명
tools/blender/build_assets.py   모델과 조명을 다시 만드는 스크립트
js/analysis.js   샷 분석·감도 추천·기록 저장과 추세 그래프
js/main.js       메뉴·진행 흐름
```

## 아직 없는 것
앞뒤 이동(W/S)과 점프, 무기별 실제 반동 패턴, 스킬, 실제 맵 지형은 아직 없습니다. 스킨의 3D 모델과 게임 원본 킬 배너도 들어 있지 않습니다.

## 확인
Node.js가 있으면 `node --test tests/*.test.cjs`로 시점·판정, 샷 분석·감도 추천·기록과 공개 주소에서의 스킨·녹화 음원 로딩을 확인할 수 있습니다.

`assets/skins/`에는 녹화해서 준비한 챔피언스·가이아 1인칭 총 이미지와 킬사운드가 포함됩니다. 공개 페이지에서도 자동으로 불러오며 연속 헤드샷 시 두 스킨 모두 1~5단계 음원을 순서대로 재생하고 5단계를 유지합니다. 가이아 4·5단계는 기존 녹화 원본에서 추가 추출했으며, 음높이를 바꿔 만든 대체음이 아닙니다. 빗맞힘·몸샷 처치·새 연습 시작 시 스택을 초기화합니다. `local/`은 로컬에서 기본 자료를 덮어쓸 때 사용하며 Git에는 포함하지 않습니다.

재생에는 `*_clean.wav` 정리본을 사용합니다. 가이아 2·5단계 끝의 별도 클릭 구간을 덜어내고, 전체 킬음에 약한 배경 잡음 감소와 시작·끝 페이드를 적용했습니다. 정리 전 원본 파일도 보존합니다.

가이아 5단계는 녹화에 겹친 사람 목소리를 분리한 `gaia_vandal_5_no_speech.wav`를 사용합니다. 전체 4.2초 길이와 잔향을 유지하며 시작·끝만 짧게 페이드 처리합니다. 오프라인 분리에 [UVR](https://github.com/Anjok07/ultimatevocalremovergui)의 MDX 모델과 [Audio Separator](https://github.com/nomadkaraoke/python-audio-separator)의 공개 추론 방식을 참고했습니다. 분리 과정과 원본은 로컬에 보존하며 앱은 처리된 WAV만 재생합니다.
