# 🎯 에임 트레이너

발로란트 조준선 코드를 그대로 붙여넣어 쓰는 브라우저 에임 연습장입니다. 설치 없이 정적 파일만으로 동작합니다.

공개 연습장: https://seungjaehh.github.io/aim-trainer/

조준선은 화면 중앙에 고정되고 마우스로 시점을 회전합니다. 바닥 타일·거리선·벽의 눈높이 띠와 표적에 하나의 원근 투영을 적용해, 위아래로 바라볼 때도 공간의 기준이 유지됩니다. 봇은 바닥에 서 있고 발밑에 그림자가 표시됩니다. 왼쪽 아래에서 현재 시선의 상하 각도를 확인할 수 있습니다.

## 연습 모드
| 모드 | 내용 |
|---|---|
| 그리드샷 | 3×3 칸 중 3개가 켜지는 클릭 정확도·속도 연습 |
| 플릭샷 | 멀리 나타나는 타겟을 한 번에 휘둘러 맞히기 |
| 마이크로 플릭 | 조준선 가까이의 작은 타겟 |
| 트래킹 | 움직이는 타겟에 마우스를 누른 채 붙여 두기 |
| 헤드라인 | 머리 높이의 봇 머리 맞히기 |
| 대기샷 | 벽 모서리에 각도를 잡고 있다가 튀어나오는 봇 맞히기 (반응 속도 측정) |
| 이동 타겟 | 스트레이프하다 멈추는 봇 맞히기 |
| 타겟 전환 | 크기·거리가 다른 타겟을 빠르게 옮겨 가며 지우기 |
| 반응 속도 | 갑자기 나타나는 타겟을 보자마자 클릭 |

대기샷은 연습 설정에서 칼 달리기(6.75 m/s)·밴달 달리기(5.40 m/s)·밴달 걷기(3.24 m/s)·앉기(약 1.90 m/s)를 고정하거나 랜덤으로 섞을 수 있습니다. 각속도가 아닌 바닥 위의 실제 거리를 기준으로 이동하며, 앉기 봇은 머리 높이도 낮아집니다. 스킬·버프는 제외합니다. [리플레이 실측 자료](https://github.com/yakisoba0728/vrfkit/blob/main/docs/DATA.md)를 참고한 연습용 근사이며, 라이엇이 공식 보증한 물리 재현은 아닙니다.

## 기능
- **내 조준선**: 발로란트 조준선 코드(`0;P;c;5;…`)를 붙여넣으면 게임과 같은 픽셀 그대로 그립니다.
- **감도**: 발로란트 감도·DPI·시야각을 넣으면 cm/360 을 계산해 줍니다 (1카운트 = 0.07°×감도).
- **킬 사운드**: 발로란트풍·딩·팝·차임·스냅 중 선택하거나 내 소리 파일을 올려 쓸 수 있습니다. 헤드샷은 더 높은 음으로 납니다.
- **밴달 스킨**: 밴달은 고정이며 [valorant-api.com](https://valorant-api.com) 에서 불러온 스킨만 선택합니다.
- **배경**: 바닥과 거리선이 있는 연습장·어두운 연습장·기존 격자 중 선택합니다.
- 설정과 최고 점수는 브라우저(localStorage)에 저장됩니다.

## 조작
- 모드를 누르면 마우스가 잠기고 3초 뒤 시작합니다. 클릭으로 사격, `T` 다시 시작, `Esc` 일시정지.

## 실행
`index.html` 을 브라우저로 열면 됩니다. 로컬 서버가 필요하면:

```bash
python -m http.server 8000
```

## GitHub Pages 로 공개
저장소를 만들어 푸시한 뒤 Settings → Pages → Branch `main` / root 를 고르면 `https://<아이디>.github.io/<저장소>/` 에서 바로 열립니다.

## 구조
```
index.html  style.css
js/settings.js   설정 저장
js/crosshair.js  조준선 코드 해석·그리기
js/audio.js      킬 사운드
js/skins.js      무기 스킨 불러오기
js/engine.js     시점·투영·사격 판정·렌더
js/modes.js      연습 모드 (새 모드는 여기에 객체 하나만 추가)
js/main.js       메뉴·진행 흐름
```

## 아직 없는 것
스프레이 컨트롤, 이동 중 사격 정확도(카운터 스트레이프) 같은 무기 반동 연습은 아직 없습니다.

## 확인
Node.js가 있으면 `node --test tests/*.test.cjs`로 시점·판정과 공개 주소에서의 스킨·녹화 음원 로딩을 확인할 수 있습니다.

`assets/skins/`에는 녹화해서 준비한 챔피언스·가이아 1인칭 총 이미지와 킬사운드가 포함됩니다. 공개 페이지에서도 자동으로 불러오며 연속 헤드샷 시 두 스킨 모두 1~5단계 음원을 순서대로 재생하고 5단계를 유지합니다. 가이아 4·5단계는 기존 녹화 원본에서 추가 추출했으며, 음높이를 바꿔 만든 대체음이 아닙니다. 빗맞힘·몸샷 처치·새 연습 시작 시 스택을 초기화합니다. `local/`은 로컬에서 기본 자료를 덮어쓸 때 사용하며 Git에는 포함하지 않습니다.

재생에는 `*_clean.wav` 정리본을 사용합니다. 가이아 2·5단계 끝의 별도 클릭 구간을 덜어내고, 전체 킬음에 약한 배경 잡음 감소와 시작·끝 페이드를 적용했습니다. 정리 전 원본 파일도 보존합니다.

가이아 5단계는 녹화에 겹친 사람 목소리를 분리한 `gaia_vandal_5_no_speech.wav`를 사용합니다. 전체 4.2초 길이와 잔향을 유지하며 시작·끝만 짧게 페이드 처리합니다. 오프라인 분리에 [UVR](https://github.com/Anjok07/ultimatevocalremovergui)의 MDX 모델과 [Audio Separator](https://github.com/nomadkaraoke/python-audio-separator)의 공개 추론 방식을 참고했습니다. 분리 과정과 원본은 로컬에 보존하며 앱은 처리된 WAV만 재생합니다.
